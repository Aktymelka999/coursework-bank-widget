# Курсовая работа: Аналитический виджет банковских транзакций

Проект на Python для анализа истории операций и генерации JSON-структур для фронтенд-виджета.

## Функционал

Проект реализует полный цикл обработки транзакций:
*   **Загрузка данных:** Чтение Excel-файла (`data/operations.xlsx`) с валидацией.
*   **Генерация JSON для экранов:**
    *   Главная страница (приветствие, список карт, топ транзакций).
    *   События и календарь (агрегация по периодам).
    *   Инвесткопилка (расчёт сумм).
    *   Поиск (по названию магазина, по телефону).
    *   Отчёты (по категориям, дням недели, типу дня).
*   **Аналитика:** Автоматический расчёт общей суммы, среднего чека и топ-категорий.
*   **Устойчивость:** Обработка ошибок (отсутствие файла, неверные колонки) с понятными сообщениями.

## Как запустить

1.  Активируй виртуальное окружение:
    ```powershell
    .\.venv\Scripts\Activate.ps1
    ```
2.  Установи зависимости:
    ```powershell
    pip install -r requirements.txt
    ```
3.  Запусти полный прогон всех отчётов:
    ```powershell
    python -m src.main
    ```

## Структура проекта

| Папка/Файл | Назначение |
| :--- | :--- |
| `data/` | Исходные данные (`operations.xlsx`). |
| `src/` | Основной код приложения. |
| `src/main.py` | Точка входа, оркестратор всех отчётов. |
| `src/utils.py` | Загрузка и базовая валидация данных. |
| `src/views.py` | Логика формирования JSON для каждого экрана виджета. |
| `logs/` | Файлы логов (`masks.log`, `utils.log`). |
| `tests/` | Юнит-тесты (заготовки). |
| `fix_excel.py` | Утилита для восстановления тестовых данных. |

## Особенности реализации

*   **Модульность:** Логика разделена на загрузку данных, формирование представлений (views) и основную логику.
*   **JSON-API:** Все функции возвращают словари (dict), готовые к сериализации в JSON для фронтенда.
*   **Защита от сбоев:** Блок `try-except` в `main.py` предотвращает падение программы при отсутствии файла или ошибках в данных.
*   **Аналитика:** В конце прогона выводится сводный отчёт с топ-категориями и средним чеком.
